## 条件表达（N5 で学んだ ば/たら/なら の応用）||Conditionals (building on the ば/たら/なら learned in N5)

- [ ] 〜ても — 即使~也~ // 〜ても — even if ~
- [ ] 〜場合は — 在~情况下 // 〜場合は — in case of ~ / if ~ happens
- [ ] 〜たらどう — 做~怎么样？（建议） // 〜たらどう — why don't you ~? (suggestion)

## 受身形（被动）||Passive Form

- [ ] 直接受身 — 被~做（食べられる） // 直接受身 — direct passive: be ~ed (食べられる)
- [ ] 間接受身（迷惑の受身）— 被~（不情愿/受害） // 間接受身（迷惑の受身）— indirect / "suffering" passive: be adversely affected by ~
- [ ] 持ち主の受身 — 所有者被动（足を踏まれた） // 持ち主の受身 — possessor passive: have one's ~ done to (足を踏まれた)
- [ ] 〜によって — 被~（正式，施动者标志） // 〜によって — by ~ (formal marker of the agent)

## 使役形||Causative Form

- [ ] 使役形変形 — せる/させる（三类动词规则） // 使役形変形 — forming the causative: せる/させる (rules for the three verb groups)
- [ ] 強制の使役 — 强制做（〜を〜させる） // 強制の使役 — make someone do (〜を〜させる)
- [ ] 許可の使役 — 允许做（〜に〜させる） // 許可の使役 — let someone do (〜に〜させる)
- [ ] 使役受身形 — 被迫做（〜させられる） // 使役受身形 — causative-passive: be made to do (〜させられる)

## 授受表现||Giving and Receiving

- [ ] あげる — 给（说话人→他人 / 他人→他人） // あげる — give (speaker → others / others → others)
- [ ] もらう — 得到（说话人←他人） // もらう — receive (speaker ← others)
- [ ] くれる — 给我（他人→说话人/内群） // くれる — give to me (others → speaker / speaker's in-group)
- [ ] 〜てあげる — 为~做（动作授受） // 〜てあげる — do ~ for someone (giving an action)
- [ ] 〜てもらう — 请~做/得到~做 // 〜てもらう — have someone do ~ / get ~ done by someone
- [ ] 〜てくれる — 为我做~ // 〜てくれる — (someone) does ~ for me
- [ ] 差し上げる/いただく/くださる — 敬语版授受 // 差し上げる/いただく/くださる — honorific / humble giving and receiving

## ように 系列||The ように Family

- [ ] 〜ようになる — 变得能够/开始~ // 〜ようになる — come to be able to ~ / start to ~
- [ ] 〜ないようにする — 注意不要~ // 〜ないようにする — make sure not to ~
- [ ] 〜ように（目的）— 为了（不可控动词） // 〜ように (purpose) — so that (with non-volitional verbs)

## ことに 系列||The ことに Family

- [ ] 〜ことになる — 变成了~（被决定） // 〜ことになる — it has been decided that ~ (decided for you)
- [ ] 〜ことになっている — 规定是~/预定是~ // 〜ことになっている — the rule is ~ / it's arranged that ~

## 补助动词||Auxiliary Verbs

- [ ] 〜てしまう（ちゃう/じゃう）— 做完了/遗憾 // 〜てしまう (ちゃう/じゃう) — finish completely / regret
- [ ] 〜ておく（とく）— 事先准备/放置不管 // 〜ておく (とく) — do in advance / leave as is
