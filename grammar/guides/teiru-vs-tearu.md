# ている・てある・ておく 的区别 — 状态与准备总结||ている vs てある vs ておく (te iru, te aru, te oku) — The Complete Guide

:::zh
"窗户开着"日语可以说 窓が開いている，也可以说 窓が開けてある；"先把窗户打开"又是 窓を開けておく。三个都是"て形＋补助动词"，区别在于：**有没有人特意做**、**说的是动作还是结果**、**站在看的人还是做的人的角度**。关键还要分清自动词和他动词。这一页把 [Lesson 05](/lesson05/) 的ている和 [Lesson 24](/lesson24/) 的てある・ておく放在一起：先给一句话结论和对比总表，再按 7 种场景对比，最后用判断流程和 10 道自测题收尾。
:::
:::en
"The window is open" can be 窓が開いている or 窓が開けてある, and "open the window (in advance)" is 窓を開けておく. All three are a て-form plus a helper verb. What sets them apart: **whether someone did it on purpose**, **whether you're talking about the action or its result**, and **whether you speak as the observer or the doer** — and you need to tell intransitive verbs from transitive ones. This page brings together ている from [Lesson 05](/lesson05/) and てある / ておく from [Lesson 24](/lesson24/): a short answer and comparison table first, then seven situations side by side, and finally a decision flow and a 10-question self-test.
:::

## 一句话结论||The Short Answer

:::zh
- **ている**：持续动词＝"正在做"（料理を作っている）；变化类动词＝"变化后的状态"（窓が開いている）。只描述，不管是谁做的、是不是故意的。
- **てある**：**他动词**＋てある＝"有人特意做了，结果留在那里"（窓が開けてある）。从**看到结果的人**的角度说，助词一般用**が**。
- **ておく**：为了之后，**现在先做好**，或者"先保持这样别动"（窓を開けておく）。从**做的人**的角度说，动词原来的**を**不变。

判断时问自己：**我在说眼前的状态，还是说我（为之后）要做/做了的事？** 说状态：有人为意图用てある，单纯描述用ている；说自己的准备用ておく。
:::
:::en
- **ている**: with action verbs, "is doing" (料理を作っている); with change verbs, "the state after the change" (窓が開いている). It just describes — who did it, and whether on purpose, doesn't matter.
- **てある**: **transitive verb** + てある = "someone did this on purpose and the result is still there" (窓が開けてある). Told from **the viewpoint of someone seeing the result**; the particle is usually **が**.
- **ておく**: **do it now** for later, or "leave it as it is" (窓を開けておく). Told from **the doer's viewpoint**; the verb keeps its own **を**.

Ask yourself: **am I describing a state in front of me, or something I do (or did) for later?** A state: deliberate → てある, plain description → ている. Your own preparation → ておく.
:::

## 对比总表||Comparison Table

:::zh
| 维度 | 自动词＋ている | 他动词＋ている | 他动词＋てある | ておく |
|------|------|------|------|------|
| 意思 | 变化后的状态（持续动词则是"正在"） | 动作正在进行 | 有人有意做了，结果保留 | 事先做好；保持原状 |
| 例 | 窓が開いている | 店員が商品を並べている | 窓が開けてある | 窓を開けておく |
| 助词 | が | を | が（也常用は） | 跟着动词走（他动词用を） |
| 有没有人为 | 不管 | 有做的人 | 一定有，通常不说是谁 | 一定有目的 |
| 视角 | 看到的状态 | 看到的动作 | 看到的结果 | 做的人 |
| 时间 | 现在 | 现在 | 现在的状态（已经做好） | 将来、过去都可以 |
| 口语缩略 | 〜てる | 〜てる | 一般不缩略 | 〜とく |
:::
:::en
| Aspect | intransitive + ている | transitive + ている | transitive + てある | ておく |
|------|------|------|------|------|
| Meaning | State after a change ("is doing" for action verbs) | Action in progress | Done on purpose, result remains | Done in advance; left as is |
| Example | 窓が開いている | 店員が商品を並べている | 窓が開けてある | 窓を開けておく |
| Particle | が | を | が (often は) | Whatever the verb takes (を for transitive) |
| Someone's intent? | Doesn't matter | There is a doer | Always, usually not named | Always a purpose |
| Viewpoint | The state you see | The action you see | The result you see | The doer |
| Time | Now | Now | Present state (already done) | Future or past |
| Casual form | 〜てる | 〜てる | Usually not shortened | 〜とく |
:::

## 场景对比||Situation by Situation

### 场景 1：ている 的两个意思||Situation 1: The two meanings of ている

:::zh
- 母は台所で料理を作っ**ている**。（妈妈正在厨房做饭。→ 动作进行中）
- 子供たちが公園で遊ん**でいる**。（孩子们正在公园玩。）
- 父はもう家に帰っ**ている**。（爸爸已经回到家了。→ 回来之后的状态）
- 田中さんは結婚し**ている**。（田中已婚。→ 结婚之后的状态）

→ 作る、遊ぶ这类能持续的动作＋ている＝"正在"；帰る、結婚する、開く这类一下子完成的变化＋ている＝"变化后的状态"。
:::
:::en
- 母は台所で料理を作っ**ている**。(My mother is cooking in the kitchen. → an action in progress)
- 子供たちが公園で遊ん**でいる**。(The children are playing in the park.)
- 父はもう家に帰っ**ている**。(My father is already home. → the state after coming back)
- 田中さんは結婚し**ている**。(Tanaka is married. → the state after getting married)

→ Actions that last (作る, 遊ぶ) + ている = "is doing"; changes that happen in a moment (帰る, 結婚する, 開く) + ている = "the state after the change".
:::

### 场景 2：自动词＋ている vs 他动词＋てある||Situation 2: Intransitive + ている vs transitive + てある

:::zh
- 窓が開い**ている**。（窗户开着。→ 只描述状态，不管是谁开的、为什么开）
- 窓が開け**てある**。（窗户被人打开着。→ 有人特意开的，比如为了通风）
- ドアに鍵がかかっ**ている**。（门锁着。）
- ドアに鍵がかけ**てある**。（门已经上了锁。→ 有人锁好的，带着"防范"的意图）

→ 两种说法助词都是が，区别只在动词：自动词（開く・閉まる・つく・消える・かかる・並ぶ・入る）＋ている，他动词（開ける・閉める・つける・消す・かける・並べる・入れる）＋てある。
:::
:::en
- 窓が開い**ている**。(The window is open. → a plain description; who opened it, or why, doesn't matter)
- 窓が開け**てある**。(The window has been left open. → someone opened it on purpose, e.g. to air the room)
- ドアに鍵がかかっ**ている**。(The door is locked.)
- ドアに鍵がかけ**てある**。(The door has been locked. → someone locked it, as a precaution)

→ Both take が; only the verb differs: intransitive (開く・閉まる・つく・消える・かかる・並ぶ・入る) + ている, transitive (開ける・閉める・つける・消す・かける・並べる・入れる) + てある.
:::

### 场景 3：他动词：正在做 vs 已经做好||Situation 3: Transitive verbs — doing it vs done

:::zh
- 店員が棚に商品を並べ**ている**。（店员正在往架子上摆商品。→ 动作进行，用を）
- 棚に商品が並べ**てある**。（架子上已经摆好了商品。→ 动作的结果，用が）
- 棚に商品が並ん**でいる**。（架子上摆着商品。→ 自动词，单纯描述）

→ 同一个他动词，＋ている说的是"动作本身"，＋てある说的是"动作留下的结果"。用てある时，原来的宾语（商品を）变成主语（商品が）。
:::
:::en
- 店員が棚に商品を並べ**ている**。(A clerk is putting goods out on the shelves. → action in progress, with を)
- 棚に商品が並べ**てある**。(Goods have been set out on the shelves. → the result of the action, with が)
- 棚に商品が並ん**でいる**。(There are goods lined up on the shelves. → intransitive, a plain description)

→ With the same transitive verb, + ている is about the action itself; + てある is about the result it left behind. With てある, the original object (商品を) becomes the subject (商品が).
:::

### 场景 4：有没有人特意做||Situation 4: Did someone do it on purpose?

:::zh
- 道に財布が落ち**ている**。（路上掉着一个钱包。→ 不是故意的，只能用ている）
- 玄関に傘が置い**てある**。（门口放着伞。→ 有人放在那里的）
- 誰もいないのに、電気がつい**ている**。（明明没人，灯却开着。→ 只说状态，可能是忘了关）
- 会議室はもうエアコンがつけ**てある**。（会议室的空调已经开好了。→ 有人为了开会提前开的）

→ てある 一定暗示"背后有人有意这么做"，而且常常是"为了之后"。不是故意的事（掉了、坏了）不用てある。
:::
:::en
- 道に財布が落ち**ている**。(There's a wallet lying on the road. → no one meant it, so only ている works)
- 玄関に傘が置い**てある**。(There's an umbrella left at the entrance. → someone put it there)
- 誰もいないのに、電気がつい**ている**。(Nobody's here, but the light is on. → just the state; maybe someone forgot)
- 会議室はもうエアコンがつけ**てある**。(The air conditioning in the meeting room has already been turned on. → someone did it ahead of the meeting)

→ てある always implies that someone did it deliberately, often with a later purpose in mind. Accidental things (dropped, broken) don't take てある.
:::

### 场景 5：没有对应自动词的动词||Situation 5: Verbs with no intransitive partner

:::zh
- 黒板に明日の予定が書い**てある**。（黑板上写着明天的安排。）
- 壁にカレンダーが貼っ**てある**。（墙上贴着日历。）
- テーブルに花が飾っ**てある**。（桌上摆着花。）
- ❌ 黒板に予定が書いている

→ 書く、貼る、置く、飾る 没有对应的自动词，要说"（东西）……着"的状态，只能用てある。"が＋書いている"会变成"（东西）在写"，说不通。
:::
:::en
- 黒板に明日の予定が書い**てある**。(Tomorrow's schedule is written on the blackboard.)
- 壁にカレンダーが貼っ**てある**。(There's a calendar up on the wall.)
- テーブルに花が飾っ**てある**。(Flowers have been arranged on the table.)
- ❌ 黒板に予定が書いている

→ 書く, 貼る, 置く and 飾る have no intransitive partner, so to describe the resulting state of a thing, てある is the only option. が + 書いている would mean the thing itself is writing, which makes no sense.
:::

### 场景 6：ておく：为之后先做好||Situation 6: ておく — doing it now for later

:::zh
- 旅行の前に、ガイドブックを読ん**でおく**。（旅行前先把旅游指南读一遍。）
- 明日は早いから、今日は早く寝**ておこう**。（明天要早起，今天先早点睡吧。→ 自动词也行，只要是有意识的动作）
- 友達が来るから、ジュースを買っ**といた**。（朋友要来，我先买好了果汁。→ ておいた 的口语）
- まだ使うから、パソコンはつけ**ておいて**。（还要用，电脑先开着别关。→ 保持原状）

→ ておく 的重点是"有目的地先做"，可以说将来的事，也可以说已经做完的事。助词跟着动词走：他动词就用を。
:::
:::en
- 旅行の前に、ガイドブックを読ん**でおく**。(Before the trip, I'll read the guidebook.)
- 明日は早いから、今日は早く寝**ておこう**。(I have an early start tomorrow, so I'll get to bed early tonight. → intransitive verbs work too, as long as the action is deliberate)
- 友達が来るから、ジュースを買っ**といた**。(A friend's coming over, so I bought some juice. → casual for ておいた)
- まだ使うから、パソコンはつけ**ておいて**。(I'm still using it, so leave the computer on. → leaving things as they are)

→ The point of ておく is doing something with a purpose ahead of time; it works for the future and for things already done. The particle follows the verb: を for transitive verbs.
:::

### 场景 7：ておく vs てある：同一件事的两个角度||Situation 7: ておく vs てある — two sides of the same act

:::zh
- ビールを冷やし**ておいた**よ。（我把啤酒冰好了哦。→ 做的人的角度，を）
- 冷蔵庫にビールが冷やし**てある**よ。（冰箱里冰着啤酒哦。→ 看到结果的角度，が）
- ホテルはもう予約し**てある**。（酒店已经订好了。→ 现在的状态）
- 明日までに、ホテルを予約し**ておきます**。（我明天之前把酒店订好。→ 还没做，只能用ておく）

→ 我用"ておいた"做好的事，在别人看来就是"てある"的状态。てある 说的是"现在已经是这个状态"，不能说还没做的事。另外，"もうホテルを予約してある"这样用を也可以，意思偏向"这件事已经办好了"，和ておいた很接近。
:::
:::en
- ビールを冷やし**ておいた**よ。(I put some beer in to chill. → the doer's viewpoint, を)
- 冷蔵庫にビールが冷やし**てある**よ。(There's beer chilling in the fridge. → seen as a result, が)
- ホテルはもう予約し**てある**。(The hotel's already booked. → the present state)
- 明日までに、ホテルを予約し**ておきます**。(I'll book the hotel by tomorrow. → not done yet, so only ておく)

→ What I did with ておいた is, to anyone looking, a てある state. てある describes how things already are, so it can't be used for something not yet done. You can also say もうホテルを予約してある with を; it then leans toward "that task is already taken care of", close to ておいた.
:::

## 判断流程||Decision Flow

:::zh
1. 说的是为之后做准备、或"先保持这样"（将来或过去）？→ **ておく**（助词跟着动词，他动词用を）
2. 说的是正在进行的动作？→ **ている**（他动词用を）
3. 说眼前的状态，而且想表达"是有人特意弄好的"？→ **他动词＋てある**（が）
4. 只是描述状态，不管是谁、是不是故意的？→ **自动词＋ている**（が）
5. 动词没有对应的自动词（書く・貼る・置く・飾る），又要说状态？→ **てある**
:::
:::en
1. Is it preparation for later, or "leave it as it is" (future or past)? → **ておく** (the verb keeps its particle; を for transitive)
2. Is it an action in progress? → **ている** (を for transitive)
3. Is it a state in front of you, and you want to say someone arranged it on purpose? → **transitive + てある** (が)
4. Just describing a state, regardless of who or whether on purpose? → **intransitive + ている** (が)
5. The verb has no intransitive partner (書く・貼る・置く・飾る) and you want the state? → **てある**
:::

## 常见错误||Common Mistakes

:::zh
| 错误 | 正确 | 原因 |
|------|------|------|
| ❌ 窓が開いてある | ✅ 窓が開けてある／窓が開いている | てある只接他动词 |
| ❌ 窓が開けている（想说"窗户开着"） | ✅ 窓が開いている | 用が描述状态，要用自动词＋ている |
| ❌ 壁にポスターが貼っている | ✅ 壁にポスターが貼ってある | 貼る没有自动词，状态用てある |
| ❌ 道に財布が落としてある（捡到的钱包） | ✅ 道に財布が落ちている | 这不是故意的，不用てある |
| ❌ 明日、資料をコピーしてある | ✅ 明日、資料をコピーしておく | 还没做的准备用ておく |
| ❌ 私がビールが冷やしておいた | ✅ 私がビールを冷やしておいた | ておく保留他动词的を |
:::
:::en
| Wrong | Correct | Reason |
|------|------|------|
| ❌ 窓が開いてある | ✅ 窓が開けてある／窓が開いている | てある only takes transitive verbs |
| ❌ 窓が開けている (meaning "the window is open") | ✅ 窓が開いている | To describe a state with が, use intransitive + ている |
| ❌ 壁にポスターが貼っている | ✅ 壁にポスターが貼ってある | 貼る has no intransitive partner, so the state takes てある |
| ❌ 道に財布が落としてある (a wallet you found) | ✅ 道に財布が落ちている | Accidents don't take てある |
| ❌ 明日、資料をコピーしてある | ✅ 明日、資料をコピーしておく | Future preparation takes ておく |
| ❌ 私がビールが冷やしておいた | ✅ 私がビールを冷やしておいた | ておく keeps the transitive verb's を |
:::

## 练习：自测||Practice: Self-Test

:::zh
第 1–9 题在（　）里填 いる・ある・おく 的适当形式；第 10 题填助词。
:::
:::en
For 1–9, fill each blank with the right form of いる, ある or おく; for 10, fill in a particle.
:::

1. 風で窓が開いて（　）。
2. 換気のために、窓が開けて（　）。
3. 黒板に明日の予定が書いて（　）。
4. 道に財布が落ちて（　）。
5. お客さんが来る前に、部屋を片付けて（　）ます。
6. 母は今、台所で晩ご飯を作って（　）。
7. 壁に地図が貼って（　）から、それを見てください。
8. 明日の会議の資料、今日中にコピーして（　）てください。
9. まだ使うから、エアコンはつけて（　）て。
10. 私がビール（　）冷やしておいたよ。

### 答案与解析||Answers and Explanations

<details>
<summary>点击查看答案 / Show answers</summary>

:::zh
1. **いる** —— 開く是自动词，被风吹开，没有人为意图。
2. **ある** —— 開ける是他动词，有人为了通风特意打开。
3. **ある** —— 書く没有自动词，"写着"只能用てある。
4. **いる** —— 落ちる是自动词，不是故意的。
5. **おき** —— 这是客人来之前的事先准备：片付けておきます。
6. **いる** —— 正在做饭，动作进行中。
7. **ある** —— 有人贴好的地图，结果状态。
8. **おい** —— 请对方为开会先复印好：コピーしておいてください。
9. **おい** —— 先开着别关，保持原状：つけておいて。
10. **を** —— ておく是做的人的角度，冷やす的宾语用を。
:::
:::en
1. **いる** — 開く is intransitive; the wind blew it open, no one meant it.
2. **ある** — 開ける is transitive; someone opened it on purpose to air the room.
3. **ある** — 書く has no intransitive partner, so "is written" needs てある.
4. **いる** — 落ちる is intransitive, and it wasn't on purpose.
5. **おき** — tidying up before guests arrive is preparation: 片付けておきます.
6. **いる** — she's cooking right now, an action in progress.
7. **ある** — someone put the map up; a resulting state.
8. **おい** — asking someone to make copies ahead of the meeting: コピーしておいてください.
9. **おい** — leave it on, as it is: つけておいて.
10. **を** — ておく is the doer's viewpoint, so the object of 冷やす takes を.
:::

</details>
