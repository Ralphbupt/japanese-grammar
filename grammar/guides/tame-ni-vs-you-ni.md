# ために vs ように — 表目的的区别与用法总结||ために vs ように (tame ni vs you ni) — Purpose Explained

:::zh
ために和ように都能翻成"为了……"，所以很多人凭感觉二选一，结果一半对一半错。其实它们分工很清楚：看前面的动词是不是"自己想做就能做"的动作。这一页把 [Lesson 15](/lesson15/)（ために）、[Lesson 21](/lesson21/)（ように）和 [Lesson 37](/lesson37/)（表原因的ために）里的规则放在一起：一句话结论、对比总表、7 种典型场景、判断流程，最后是 10 道自测题。
:::
:::en
ために (tame ni) and ように (you ni) can both be translated "in order to / so that", so many learners pick one by feel and get it right about half the time. The split is actually clean: it depends on whether the verb before it is something you can simply decide to do. This page pulls together the rules from [Lesson 15](/lesson15/) (ために), [Lesson 21](/lesson21/) (ように) and [Lesson 37](/lesson37/) (ために for cause): a one-line answer, a comparison table, seven typical situations, a decision flow, and a 10-question self-test.
:::

## 一句话结论||The Short Answer

:::zh
- **ために**：前面是**自己能直接决定去做**的动作（意志动词辞书形），或者名词＋の。"为了做 X，所以做 Y"。前后主语原则上相同。
- **ように**：前面是**不能靠意志直接做到**的结果——可能形（話せる）、わかる・見える・聞こえる、ない形、自然的变化。"为了让 X 这种状态成立，所以做 Y"。前后主语可以不同。

判断时问自己一句：**"X"本身是一个动作，还是一个希望达到的状态？** 动作用ために，状态用ように。
:::
:::en
- **ために**: what comes before is an **action you can simply choose to do** (a volitional verb in dictionary form), or a noun + の. "Do Y in order to do X." As a rule, both clauses share the same subject.
- **ように**: what comes before is **a result you can't produce just by deciding to** — a potential form (話せる), わかる・見える・聞こえる, a ない-form, a natural change. "Do Y so that state X will hold." The two clauses can have different subjects.

Ask one question: **is X an action, or a state you hope to reach?** Action → ために. State → ように.
:::

## 对比总表||Comparison Table

:::zh
| 维度 | ために | ように |
|------|------|------|
| 前面的词 | 意志动词辞书形（買う・行く・勉強する） | 可能形、わかる・見える・聞こえる、ない形、〜くなる/〜になる |
| 名词 | 名词＋のために（健康のために） | 名词＋のように 是"像……一样"，不表目的 |
| 前后主语 | 原则上相同 | 可以不同（子供が遊べるように、私が…） |
| 否定 | 考试中一般不用 〜ないために | 〜ないように（最常见） |
| 其他意思 | 为了某人的利益（家族のために）；表原因（台風のために） | ようにする・ようになる・ように言う 这类句型 |
| 中文感觉 | "为了去做……" | "为了能……" / "以免……" |
:::
:::en
| Aspect | ために | ように |
|------|------|------|
| What comes before | Volitional verb, dictionary form (買う・行く・勉強する) | Potential form, わかる・見える・聞こえる, ない-form, 〜くなる / 〜になる |
| Nouns | Noun + のために (健康のために) | Noun + のように means "like…", not purpose |
| Subjects | Same subject, as a rule | Can differ (子供が遊べるように、私が…) |
| Negatives | 〜ないために is generally avoided in tests | 〜ないように (very common) |
| Other meanings | For someone's benefit (家族のために); cause (台風のために) | Patterns such as ようにする・ようになる・ように言う |
| English feel | "in order to (do)…" | "so that (one can)…" / "so as not to…" |
:::

## 场景对比||Situation by Situation

### 场景 1：为了去做某个动作 → ために||Situation 1: In order to do an action → ために

:::zh
- 新しいパソコンを買う**ために**、アルバイトをしています。（为了买新电脑，我在打工。）
- 一番早い電車に乗る**ために**、五時に起きた。（为了赶最早的那班电车，五点就起床了。）
- 友達の結婚式に出る**ために**、大阪へ行きます。（为了参加朋友的婚礼，我要去大阪。）
- 論文を書く**ために**、図書館で資料を集めている。（为了写论文，正在图书馆收集资料。）

→ 買う・乗る・出る・書く 都是"想做就能去做"的动作，主语也是同一个人，所以用ために。
:::
:::en
- 新しいパソコンを買う**ために**、アルバイトをしています。(I'm working part-time in order to buy a new computer.)
- 一番早い電車に乗る**ために**、五時に起きた。(I got up at five in order to catch the first train.)
- 友達の結婚式に出る**ために**、大阪へ行きます。(I'm going to Osaka to attend a friend's wedding.)
- 論文を書く**ために**、図書館で資料を集めている。(I'm gathering material at the library in order to write my thesis.)

→ 買う・乗る・出る・書く are all actions you can simply go and do, and the subject is the same person throughout, so ために.
:::

### 场景 2：为了"能够……" → ように||Situation 2: So that something becomes possible → ように

:::zh
- 後ろの席の人にも見える**ように**、字を大きく書いた。（为了让后排的人也看得见，把字写得很大。）
- 外国の人にもわかる**ように**、やさしい日本語で説明した。（为了让外国人也能听懂，用简单的日语做了说明。）
- 日本の会社で働く**ために**、日本語を勉強している。（为了去日本的公司工作而学日语。→ "工作"是要去做的动作）
- 日本の会社で働ける**ように**、日本語を勉強している。（为了将来能在日本的公司工作而学日语。→ "能工作"是希望达到的状态）

→ 見える・わかる・可能形 都不是想做就能做到的，所以用ように。后两句只差一个可能形，助词就跟着变。
:::
:::en
- 後ろの席の人にも見える**ように**、字を大きく書いた。(I wrote big so that people in the back row could see too.)
- 外国の人にもわかる**ように**、やさしい日本語で説明した。(I explained in simple Japanese so that foreigners could understand too.)
- 日本の会社で働く**ために**、日本語を勉強している。(I'm studying Japanese in order to work at a Japanese company. → "work" is an action to go and do)
- 日本の会社で働ける**ように**、日本語を勉強している。(I'm studying Japanese so that I'll be able to work at a Japanese company. → "be able to work" is a state to reach)

→ 見える, わかる and potential forms aren't things you can do just by deciding to, so ように. The last two sentences differ only by the potential form, and the particle changes with it.
:::

### 场景 3：为了"不要……" → ないように||Situation 3: So as not to… → ないように

:::zh
- 風邪をひかない**ように**、毎朝うがいをしている。（为了不感冒，每天早上漱口。）
- 道に迷わない**ように**、駅からの地図を印刷しておいた。（为了不迷路，事先打印了从车站过去的地图。）
- 電車に乗り遅れない**ように**、少し早めに家を出ましょう。（为了不误车，早点出门吧。）
- 大事なことを忘れない**ように**、手帳に書いておく。（为了不忘记重要的事，记在手账上。）

→ "不感冒""不迷路"都是希望出现的结果，不是一个动作，所以用ないように。现实中也能听到「失敗しないために」这类说法，但教科书和 JLPT 的标准答案是 **ないように**。
:::
:::en
- 風邪をひかない**ように**、毎朝うがいをしている。(I gargle every morning so I won't catch a cold.)
- 道に迷わない**ように**、駅からの地図を印刷しておいた。(I printed a map from the station so I wouldn't get lost.)
- 電車に乗り遅れない**ように**、少し早めに家を出ましょう。(Let's leave a little early so we don't miss the train.)
- 大事なことを忘れない**ように**、手帳に書いておく。(I write important things in my planner so I won't forget them.)

→ "Not catching a cold" and "not getting lost" are outcomes you hope for, not actions, so ないように. You will hear phrases like 「失敗しないために」 in real life, but the textbook and JLPT answer is **ないように**.
:::

### 场景 4：前后主语不同 → ように||Situation 4: Different subjects → ように

:::zh
- 子供がけがをしない**ように**、テーブルの角にカバーをつけた。（为了不让孩子受伤，给桌角装了保护套。）
- 祖母にも読める**ように**、手紙は大きな字で書いた。（为了让奶奶也能看清，信是用大字写的。）
- 猫が入らない**ように**、窓を閉めておいた。（为了不让猫进来，把窗户关好了。）

→ 前半句的主角是孩子、奶奶、猫，后半句做事的是"我"。两边主语不同时，用ように表达"为了让对方/事物达到某种状态"。
:::
:::en
- 子供がけがをしない**ように**、テーブルの角にカバーをつけた。(I put covers on the table corners so the kids won't get hurt.)
- 祖母にも読める**ように**、手紙は大きな字で書いた。(I wrote the letter in big characters so my grandmother could read it too.)
- 猫が入らない**ように**、窓を閉めておいた。(I closed the window so the cat wouldn't get in.)

→ The first clause is about the kids, the grandmother, the cat; the person acting in the second clause is "me". When the subjects differ, ように expresses "so that someone or something else ends up in a certain state".
:::

### 场景 5：名词前面只能用のために||Situation 5: After a noun, only のために expresses purpose

:::zh
- 試験の**ために**、新しい辞書を買った。（为了考试，买了本新词典。）
- 健康の**ために**、なるべく階段を使っています。（为了健康，尽量走楼梯。）
- 子供たちの**ために**、絵本をたくさん買ってきた。（为了孩子们，买回来很多绘本。→ 为了谁的利益）
- 夢の**ように**楽しい一日だった。（像梦一样快乐的一天。→ 名词＋のように是比喻，不是目的）

→ "名词＋のために"可以表示目的或"为了某人"。"名词＋のように"只表示"像……一样"。想用ように表目的，得先变成动词：健康でいられるように。
:::
:::en
- 試験の**ために**、新しい辞書を買った。(I bought a new dictionary for the exam.)
- 健康の**ために**、なるべく階段を使っています。(For my health, I take the stairs as much as I can.)
- 子供たちの**ために**、絵本をたくさん買ってきた。(I bought lots of picture books for the kids. → for someone's benefit)
- 夢の**ように**楽しい一日だった。(It was a day as fun as a dream. → noun + のように is a comparison, not purpose)

→ Noun + のために can mean purpose or "for someone". Noun + のように only means "like…". To use ように for purpose, turn it into a verb first: 健康でいられるように.
:::

### 场景 6：〜になる 前面用哪个||Situation 6: Which one before 〜になる

:::zh
- 医者になる**ために**、大学で医学を勉強している。（为了当医生，在大学学医。）
- 歌手になる**ために**、田舎から東京に出てきた。（为了当歌手，从乡下来到了东京。）
- 早く元気になる**ように**、今日はゆっくり休んでください。（为了早点好起来，今天请好好休息。）
- 字が上手になる**ように**、毎日練習している。（为了把字写好，每天练习。）

→ なる 本身不是意志动作，但"当医生""当歌手"是自己主动追求的身份目标，用ために很自然。"好起来""变熟练"是能力、状态的变化，用ように更稳妥。现实中「上手になるために」也常听到，做题时选ように最保险。
:::
:::en
- 医者になる**ために**、大学で医学を勉強している。(I'm studying medicine at university in order to become a doctor.)
- 歌手になる**ために**、田舎から東京に出てきた。(I came to Tokyo from the countryside to become a singer.)
- 早く元気になる**ように**、今日はゆっくり休んでください。(Please get some good rest today so you'll get better soon.)
- 字が上手になる**ように**、毎日練習している。(I practise every day so my handwriting will improve.)

→ なる is not a volitional action in itself, but "becoming a doctor / a singer" is a goal you actively pursue, so ために sounds natural. "Getting better" or "improving" is a change in ability or condition, so ように is the safer choice. You will hear 「上手になるために」 too, but in a test ように is the safest answer.
:::

### 场景 7：ために还能表示原因||Situation 7: ために can also mean "because of"

:::zh
- 大雪の**ために**、学校が休みになった。（因为大雪，学校停课了。）
- 事故があった**ために**、電車が一時間も遅れた。（因为发生了事故，电车晚了整整一小时。）
- 熱が出た**ために**、試合に出られなかった。（因为发烧，没能参加比赛。）
- 日本へ行く**ために**、お金を貯めた。（为了去日本存了钱。→ 对比：这一句是目的）

→ 前面是た形、形容词或"事件名词"，后面是已经发生的结果时，ために表示原因，语气偏书面（口语多用から・ので）。ように没有表原因的用法。
:::
:::en
- 大雪の**ために**、学校が休みになった。(School was closed because of heavy snow.)
- 事故があった**ために**、電車が一時間も遅れた。(Because there was an accident, the train was a full hour late.)
- 熱が出た**ために**、試合に出られなかった。(Because I had a fever, I couldn't play in the match.)
- 日本へ行く**ために**、お金を貯めた。(I saved money in order to go to Japan. → compare: this one is purpose)

→ When the part before ために is a past form, an adjective or an event noun, and the second clause is a result that has already happened, ために means "because of". It sounds rather formal (in conversation から / ので are more common). ように has no "cause" use.
:::

## 顺带区分：ようにする・ようになる||Also Worth Knowing: ようにする and ようになる

:::zh
ように还会和 する・なる 组成固定句型，和"目的"不是一回事，详见 [Lesson 21](/lesson21/)：

- 寝る前にスマホを見ない**ようにしている**。（我注意睡前不看手机。→ ようにする：有意识地养成习惯）
- 最近、少しずつ日本のニュースが聞き取れる**ようになった**。（最近渐渐能听懂日本的新闻了。→ ようになる：自然发生的变化）
- 部長に、明日までに資料を出す**ように言われた**。（部长让我明天之前交资料。→ ように言う：转述要求）
:::
:::en
ように also combines with する and なる into set patterns that are not about purpose; see [Lesson 21](/lesson21/) for the details:

- 寝る前にスマホを見ない**ようにしている**。(I make a point of not looking at my phone before bed. → ようにする: a habit you work at)
- 最近、少しずつ日本のニュースが聞き取れる**ようになった**。(Lately I've gradually become able to follow Japanese news. → ようになる: a change that came about)
- 部長に、明日までに資料を出す**ように言われた**。(The manager told me to hand in the documents by tomorrow. → ように言う: reporting a request)
:::

## 判断流程||Decision Flow

:::zh
1. 前面是名词？→ **のために**（のように 是"像……"）
2. 前面是已经发生的事（た形），后面是结果，意思是"因为"？→ **ために**（表原因）
3. 前面是可能形、わかる・見える・聞こえる，或 ない形？→ **ように**
4. 前半句和后半句的主语不同？→ **ように**
5. 遇到 〜になる 这种说法：主动追求的身份目标 → **ために**；能力、状态的变化 → **ように**
6. 以上都不是：前面是自己能决定去做的动作，主语相同？→ **ために**
:::
:::en
1. Is it a noun? → **のために** (のように means "like…")
2. Is the first part something that already happened (past form), with a result after it, meaning "because"? → **ために** for cause
3. Is it a potential form, わかる・見える・聞こえる, or a ない-form? → **ように**
4. Do the two clauses have different subjects? → **ように**
5. Is it 〜になる? A role you actively pursue → **ために**; a change in ability or condition → **ように**
6. None of the above: an action you can decide to do, same subject? → **ために**
:::

## 常见错误||Common Mistakes

:::zh
| 错误 | 正确 | 原因 |

| ❌ 日本語が話せるために、毎日練習する | ✅ 日本語が話せるように | 可能形是状态，用ように |
| ❌ 日本語を勉強するように、日本に来た | ✅ 日本語を勉強するために | 意志动作、同一主语，用ために |
| ❌ 健康のように、野菜を食べる | ✅ 健康のために | のように 是"像……一样" |
| ❌ 学生がよくわかるために、ゆっくり話した | ✅ 学生がよくわかるように | わかる 非意志，且前后主语不同 |
| ❌ 台風が来たように、電車が止まった | ✅ 台風が来たために | 表原因只能用ために |
:::
:::en
| Wrong | Correct | Reason |
|------|------|------|

## 练习：自测||Practice: Self-Test

:::zh
在（　）里填 ために 或 ように。
:::
:::en
Fill each blank with ために or ように.
:::

1. 家を買う（　）、毎月貯金している。
2. 後ろの人にも聞こえる（　）、大きな声で話した。
3. 寝坊しない（　）、早めに寝た。
4. 将来の（　）、英語も勉強しておこう。
5. 赤ちゃんが起きない（　）、そっとドアを閉めた。
6. 留学する（　）、奨学金に申し込んだ。
7. 漢字が読める（　）、毎日五つずつ覚えている。
8. 台風の（　）、花火大会が中止になった。
9. 子供が一人で着られる（　）、ボタンの少ない服を選んだ。
10. 歌手になる（　）、毎日発声練習をしている。

### 答案与解析||Answers and Explanations

<details>
<summary>点击查看答案 / Show answers</summary>

:::zh
1. **ために** —— 買う 是意志动作，主语相同。
2. **ように** —— 聞こえる 是非意志动词，而且主语（后面的人）和说话的"我"不同。
3. **ように** —— 这里用 ない形，表示"以免……"。
4. **ために** —— 名词＋のために。
5. **ように** —— 否定＋前后主语不同（婴儿／我）。
6. **ために** —— 留学する 是意志动作。
7. **ように** —— 这里的 読める 是可能形。
8. **ために** —— 这里表原因："因为台风"。
9. **ように** —— 着られる 是可能形，主语是孩子而不是"我"。
10. **ために** —— "当歌手"是主动追求的目标。
:::
:::en
1. **ために** — 買う is a volitional action, same subject.
2. **ように** — 聞こえる is non-volitional, and the subject (the people at the back) differs from "me", the speaker.
3. **ように** — a ない-form means "so as not to…".
4. **ために** — noun + のために.
5. **ように** — a negative, plus different subjects (the baby / me).
6. **ために** — 留学する is a volitional action.
7. **ように** — 読める is a potential form.
8. **ために** — cause: "because of the typhoon".
9. **ように** — 着られる is a potential form, and the subject is the child, not me.
10. **ために** — becoming a singer is a goal actively pursued.
:::

</details>
