## 基本句型||Basic Sentence Patterns

- [ ] 〜です / 〜ではありません — 判断句（肯定/否定） // 〜です / 〜ではありません — "is / is not" (copula, affirmative/negative)
- [ ] 〜は〜です — 主题提示句型 // 〜は〜です — "As for X, it's Y" (topic sentence pattern)
- [ ] 〜も — 也 // 〜も — also, too
- [ ] 〜の — 所属/修饰助词 // 〜の — possessive / modifying particle ('s, of)
- [ ] 〜か — 疑问句标志 // 〜か — question marker
- [ ] 〜がある/〜がいる — 存在句（无生命/有生命） // 〜がある/〜がいる — there is / exists (inanimate / animate)
- [ ] 〜になる — 变成~/变得~ // 〜になる — to become ~
- [ ] 〜にする — 决定~/选择~ // 〜にする — to decide on ~ / choose ~

## 助词||Particles

- [ ] は — 主题标志 // は — topic marker
- [ ] が — 主语标志 // が — subject marker
- [ ] を — 宾语标志 // を — object marker
- [ ] に — 时间/地点/对象/方向 // に — time / location / target / direction
- [ ] で — 手段/场所/原因 // で — means / place of action / cause
- [ ] へ — 方向 // へ — direction (toward)
- [ ] と — 并列/引用/共同 // と — and (listing) / quotation / together with
- [ ] から — 起点/原因 // から — from (starting point) / because
- [ ] まで — 终点 // まで — until / up to (end point)
- [ ] より — 比较基准 // より — than (basis of comparison)
- [ ] や — 不完全列举（A和B等） // や — non-exhaustive listing (A, B, and so on)
- [ ] だけ — 只/仅仅 // だけ — only, just
- [ ] けど/けれども — 但是/可是 // けど/けれども — but, although

## 动词活用||Verb Conjugation

- [ ] ます形 — 礼貌体（肯定/否定/过去/过去否定） // ます形 — polite form (affirmative / negative / past / past negative)
- [ ] て形 — 连接形（五段动词音便规则） // て形 — connective form (sound-change rules for godan verbs)
- [ ] ない形 — 否定形 // ない形 — negative form
- [ ] た形 — 过去形 // た形 — past form
- [ ] 辞書形 — 原形 // 辞書形 — dictionary form
- [ ] 可能形 — 表示能力（〜られる/〜える） // 可能形 — potential form, ability (〜られる/〜える)
- [ ] 意向形 — 意志/提议（〜よう/〜おう） // 意向形 — volitional form, intention / "let's" (〜よう/〜おう)

## て形应用||Uses of the て-Form

- [ ] 〜ている — 正在进行/结果状态/习惯 // 〜ている — ongoing action / resulting state / habit
- [ ] 〜てください — 请求 // 〜てください — please do ~ (request)
- [ ] 〜てもいいです — 许可 // 〜てもいいです — it's OK to ~ (permission)
- [ ] 〜てはいけません — 禁止 // 〜てはいけません — must not ~ (prohibition)
- [ ] 〜てから — 之后再 // 〜てから — after doing ~, then
- [ ] 〜てあげる/てもらう/てくれる — 授受补助动词 // 〜てあげる/てもらう/てくれる — giving & receiving actions (auxiliary verbs)
- [ ] 〜てみる — 试着做~ // 〜てみる — try doing ~
- [ ] 〜てしまう — 做完了/不小心~了 // 〜てしまう — finish ~ completely / do ~ by accident

## 义务与否定||Obligation and Negation

- [ ] 〜なくてはいけない — 必须 // 〜なくてはいけない — must, have to
- [ ] 〜なくてもいい — 不必 // 〜なくてもいい — don't have to
- [ ] 〜ないでください — 请不要 // 〜ないでください — please don't ~

## 形容词||Adjectives

- [ ] い形容词活用 — 否定（〜くない）、过去（〜かった） // い-adjective conjugation — negative (〜くない), past (〜かった)
- [ ] な形容词活用 — 否定（〜ではない）、过去（〜だった） // な-adjective conjugation — negative (〜ではない), past (〜だった)
- [ ] 〜くて/〜で — 形容词て形连接 // 〜くて/〜で — adjective て-form (linking adjectives)

## 比较与程度||Comparison and Degree

- [ ] AはBより〜 — A比B更~ // AはBより〜 — A is more ~ than B
- [ ] AとBとどちらが〜 — A和B哪个更~ // AとBとどちらが〜 — which is more ~, A or B?
- [ ] 〜の中で〜が一番〜 — ~之中最~ // 〜の中で〜が一番〜 — the most ~ among ~

## 愿望与目的||Desire and Purpose

- [ ] 〜たい/〜たくない — 想要/不想要 // 〜たい/〜たくない — want to / don't want to
- [ ] 〜たがる — 第三人称想要 // 〜たがる — (someone else) wants to ~
- [ ] 〜ために — 为了（目的） // 〜ために — in order to (purpose)
- [ ] 〜ように — 为了（能力/状态变化） // 〜ように — so that (ability / change of state)

## 推测与样态||Conjecture and Appearance

- [ ] 〜でしょう/〜だろう — 推测 // 〜でしょう/〜だろう — probably (conjecture)
- [ ] 〜かもしれない — 也许 // 〜かもしれない — might, maybe
- [ ] 〜そうだ（様態）— 看起来要~ // 〜そうだ (appearance) — looks like ~ / seems about to ~
- [ ] 〜そうだ（伝聞）— 听说~ // 〜そうだ (hearsay) — I heard that ~

## 说明与理由||Explanation and Reasons

- [ ] 〜のだ/〜んだ — 解释/强调/求解释 // 〜のだ/〜んだ — explaining / emphasizing / asking for an explanation
- [ ] 〜のに — 明明~却~（转折/遗憾） // 〜のに — even though ~ (contrast / regret)
- [ ] 〜ので — 因为~（比から更委婉） // 〜ので — because ~ (softer than から)
- [ ] 〜し — 列举理由（而且~/又~又~） // 〜し — listing reasons (and also ~ / both ~ and ~)
- [ ] 〜たり〜たりする — 列举动作（又~又~） // 〜たり〜たりする — listing actions (do things like ~ and ~)

## 计划与建议||Plans and Advice

- [ ] 〜つもりだ — 打算~/计划~ // 〜つもりだ — intend to ~ / plan to ~
- [ ] 〜予定だ — 预定~/安排~ // 〜予定だ — be scheduled to ~
- [ ] 〜方がいい — 最好~（建议） // 〜方がいい — had better ~ (advice)
- [ ] 〜まだ〜ていない — 还没~ // 〜まだ〜ていない — haven't ~ yet
- [ ] 〜もう〜た — 已经~了 // 〜もう〜た — have already ~

## 其他重要句型||Other Key Patterns

- [ ] 〜ことができる — 能够（正式） // 〜ことができる — can, be able to (formal)
- [ ] 〜ことがある — 有时会/曾经~ // 〜ことがある — sometimes ~ / have (ever) done ~
- [ ] 〜前に/〜後で — 之前/之后 // 〜前に/〜後で — before / after
- [ ] 〜ながら — 一边~一边~ // 〜ながら — while ~ (doing two things at once)
- [ ] 〜とき — ~的时候 // 〜とき — when ~
- [ ] 〜と（条件）— 一~就~（自然/必然条件） // 〜と (conditional) — whenever / if ~, then naturally ~ (natural / inevitable result)
- [ ] 〜すぎる — 太~了 // 〜すぎる — too ~ / overdo ~
- [ ] 〜に行く/〜に来る — 去做~/来做~（目的） // 〜に行く/〜に来る — go to do ~ / come to do ~ (purpose)
- [ ] 〜のが好き/上手/下手 — 喜欢/擅长/不擅长做~ // 〜のが好き/上手/下手 — like / be good at / be bad at doing ~
- [ ] 〜くらい/〜ぐらい — 大约~/左右 // 〜くらい/〜ぐらい — about, approximately ~
