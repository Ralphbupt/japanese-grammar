## 书面助词（で/に 的正式替换）||Formal Particles (formal stand-ins for で / に)

- [ ] 〜において/〜における — 在~（场所/领域，=で） // 〜において/〜における — in / at ~ (place or field; formal で)
- [ ] 〜に対して/〜に対する — 对于~/与~相反 // 〜に対して/〜に対する — toward ~ / in contrast to ~
- [ ] 〜について — 关于~ // 〜について — about ~
- [ ] 〜によって/〜による — 由于~/通过~/取决于~ // 〜によって/〜による — due to ~ / by means of ~ / depending on ~
- [ ] 〜にとって — 对~来说 // 〜にとって — for ~ / from the standpoint of ~
- [ ] 〜に関して/〜に関する — 关于~（正式） // 〜に関して/〜に関する — regarding ~ (formal)
- [ ] 〜を通じて/〜を通して — 通过~/在整个~期间 // 〜を通じて/〜を通して — through ~ / throughout ~
- [ ] 〜をもとに — 以~为基础 // 〜をもとに — based on ~
- [ ] 〜に基づいて/〜に基づく — 基于~ // 〜に基づいて/〜に基づく — based on ~
- [ ] 〜にかけて — 从~到~（时间/空间范围） // 〜にかけて — from ~ to ~ (span of time or space)
- [ ] 〜にわたって/〜にわたる — 跨越~/长达~ // 〜にわたって/〜にわたる — across ~ / over (a span of) ~

## 原因・理由||Cause & Reason

- [ ] 〜おかげで — 多亏了~（积极结果） // 〜おかげで — thanks to ~ (good result)
- [ ] 〜せいで/〜せいか — 都怪~/也许是因为~ // 〜せいで/〜せいか — because of ~ (blame) / maybe because ~
- [ ] 〜ために — 因为~（客观原因） // 〜ために — because of ~ (objective cause)
- [ ] 〜以上（は）— 既然~就~ // 〜以上（は） — now that ~, (must) ~

- [ ] 〜ことから — 因为~（推理根据） // 〜ことから — from the fact that ~ (basis for a conclusion)
