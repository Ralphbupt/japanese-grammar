# 模拟模式 · 详细规格

> 2026-10-28。展开 [quiz-plan.md](quiz-plan.md) §2.2。做题组件、题型界面、存储格式沿用 [quiz-practice-spec.md](quiz-practice-spec.md)，这里只写模拟模式不同的部分。
> 下文以 N2 为例（105 分钟一场）。N3–N5 的差别（两节考试、N4/N5 言語知識・読解合并计分 /120）见 quiz-plan.md §3.2，由每级的配置决定，流程不变。聴解第二期。

---

## 1. 目标

- **摸底**：做完知道"现在考大概几分、哪科会掉到 19 分以下"
- **练时间**：N2 的 105 分钟是语汇、语法、读解同一场，时间怎么分配自己决定，这是 N2 最容易出问题的地方（见 jlpt 指南页"时间分配"）
- **复盘**：交卷后每道错题都能看解析、问 AI、进错题本

和练习模式的区别：**做题时没有任何反馈**，全部在交卷后。

## 2. 套卷

| | 说明 |
|---|---|
| 数量 | 第一期 3 套（第 1 套 11/10，第 2 套 11/17，第 3 套 11/24） |
| 结构 | 按真考顺序：問題 1–9 言語知識，問題 10–14 読解，约 73 题、读解约 11 篇 |
| 难度 | 三套难度相当，都对齐 N2 真题水平；每套每个题型的难度分布一致（`difficulty` 1/2/3 按约 3:5:2） |
| 题目 | `mockOnly: true`，不在练习模式里出现 |
| 说明文字 | 每个問題开头有日文作答说明（同真考格式，自己写），如「つぎの文の（　）に入れるのに最もよいものを、1・2・3・4から一つえらびなさい。」 |

## 3. 三种做法

| 做法 | 时间 | 内容 | 计分 |
|---|---|---|---|
| **整卷**（默认） | 105 分钟 | 問題 1–14 | 言語知識 + 読解两科 |
| 只做 文字・语汇・语法 | 30 分钟 | 問題 1–9 | 言語知識 |
| 只做 读解 | 75 分钟 | 問題 10–14 | 読解 |

分开做是给通勤、碎片时间用的。分开做完的两半**不合成一次整卷成绩**，因为没有练到整场的时间分配；结果页标"分部"。

## 4. 流程

```
套卷列表 ─▶ 说明页 ─▶ 作答（倒计时）─▶ 交卷确认 ─▶ 结果页 ─▶ 逐题复盘
                         │  ▲
                      暂停 / 离开 → 回来继续
```

### 4.1 套卷列表（`/n2-mock-test/`）

每套一张卡片：

```
┌───────────────────────────────┐
│ 第 1 套                        │
│ 最好 言語知識 34 · 読解 29（估算）│
│ 上次 11/12 · 用时 98 分钟       │
│ [复盘]  [重做]                  │
├───────────────────────────────┤
│ 第 2 套                 进行中  │
│ 已答 41/73 · 剩余 52 分钟       │
│ [继续]  [放弃]                  │
├───────────────────────────────┤
│ 第 3 套                 未做    │
│ [开始]                         │
└───────────────────────────────┘
```

同时只能有一套"进行中"。

### 4.2 说明页

- 时间、题数、各部分结构
- 建议时间分配（可在设置里改）：文字・语汇・语法 ≈ 30 分钟，读解 ≈ 70 分钟，留 5 分钟检查
- 规则：作答中看不到答案和解析，不能问 AI；不会的题先猜一个、标记，往下做
- 选做法（§3）、是否开启"时间节点提醒"（§4.3）
- 「开始」→ 计时开始

### 4.3 作答中

**顶部栏**：剩余时间 · 当前問題（如「問題 7 文法形式」）· 已答 41/73 ·「答题卡」按钮

**答题卡**（手机底部抽屉，桌面右侧常驻）：

```
問題1  ① ② ③ ④ ⑤
問題2  ⑥ ⑦ ⑧ ⑨ ⑩
…
問題11 ㊷ ㊸ ⚑ ㊺ …
        ●已答  ○未答  ⚑标记
```

点题号直接跳过去。

**每题**：
- 和练习模式同一个组件，但**提交后不判对错**，只记下选择
- 「猜的」开关、「⚑ 标记」（待会回来看）
- 可以前后翻、改答案，交卷前一直可改
- 读解：一篇文章的几道题连着，文章不变只换题

**时间**：
- 按真实时间倒计时（记开始时间戳，不靠 setInterval 累加），刷新页面、切 App 都不会错
- 时间节点提醒（可关）：开始 30 分钟时如果还没进读解，顶部提示一次"建议进入读解"；剩 10 分钟、剩 5 分钟各提示一次
- 时间到：**自动交卷**（同真考）。设置里可改成"超时继续作答"，超时部分单独记录，成绩标"超时"

**暂停**：
- 「暂停」按钮：计时停，题目遮住
- 页面在后台超过 1 分钟（`visibilitychange`）自动暂停，回来时提示"已暂停 N 分钟，继续"
- 暂停累计超过 1 分钟的成绩标"**非正式**"，仍然算分、仍然进历史，只是和正式成绩分开显示

### 4.4 交卷

- 「交卷」→ 确认框：未答 N 题、标记 N 题（可点进去看）→「确认交卷」/「再检查一下」
- 未答的题按错计（真考一样），提示"不会也要猜一个"

## 5. 结果页

### 5.1 估算分

```
言語知識   34 / 60   ✅ 过 19 分线
読解       16 / 60   ❌ 差 3 分
聴解       未测
─────────────────────────────
两科合计 50 → 聴解需要 ≥ 40 分才能总分合格
              （且聴解单科 ≥ 19）
```

- 换算：每科 = 该科答对比例 × 60，四舍五入。JLPT 是等化计分，不公开配分，**无法精确还原**，页面明确写"估算，仅供参考"，并显示成区间（±5）
- 合格判断：每科 ≥ 19 + 合计 ≥ 90。聴解没测，所以给出"聴解需要几分才能合格"，而不是直接说过没过
- 标"非正式 / 超时 / 分部 / 重做"的成绩，在这里同样显示标签

### 5.2 题型表

| 问题 | 题型 | 对 / 总 | 猜对 | 用时 |
|---|---|---|---|---|
| 1 | 漢字読み | 4/5 | 0 | 1:10 |
| 7 | 文法形式 | 6/12 | 2 | 6:30 |
| 11 | 内容理解（中文） | 4/9 | 1 | 22:15 |
| … | | | | |

- 低于 50% 标红；每行「练这个题型」→ 练习模式
- "猜对"单独列：猜对的题算分，但说明这块其实不会

### 5.3 时间分析

- 两段条形：文字・语汇・语法 实际 38 分钟 vs 建议 30；读解 实际 64 vs 建议 70
- 用时最长的 5 道题（点进去复盘）
- 交卷时剩余时间 / 是否超时
- 一句结论，规则生成：如"语汇语法多用了 8 分钟，读解最后一篇只用了 4 分钟，问题 14 错 2 题——时间分配是主要失分原因"

### 5.4 和以前比

- 历次成绩折线（每套、每次，按日期）：言語知識、読解两条线，19 分线画虚线
- 同一套重做的成绩标"重做"，因为题目做过一遍，分数偏高

### 5.5 下一步

- 「复盘错题」（§6）
- 「错题全部加入错题本」（默认勾选所有错题和猜对的题，可取消个别）
- 「🤖 AI 诊断」：把题型得分、时间分析、错题对应的语法点和题型发给 AI，输出"接下来 1–2 周练什么"，每条带练习入口链接（见 quiz-plan.md §2.3 ③）
- 「去练最弱的题型」

## 6. 逐题复盘

- 按題目顺序，或筛选：只看错题 / 只看猜的 / 只看标记的
- 每题：题干、你的答案、正确答案、固定解析、相关语法浮层、「🤖 AI 讲解」——和练习模式解析一样（quiz-practice-spec.md §3.2、§3.4）
- 读解题：文章 + 这篇的全部题目一起显示，正确答案在文中对应的句子高亮（题目 json 加 `evidence` 字段，存文章里的位置）
- 复盘时可以单题"重新作答"，结果不改变这次的分数，但计入练习统计

## 7. 数据

### 7.1 套卷文件

`questions/N2/mock-1.json`：

```jsonc
{
  "id": "n2-mock-1",
  "level": "N2",
  "title": { "zh": "第 1 套", "en": "Test 1" },
  "minutes": 105,
  "scoring": [                              // 计分科目，来自级别配置；N4/N5 为 [{ "key": "gengo-dokkai", "max": 120, "min": 38 }]
    { "key": "gengo", "max": 60, "min": 19 },
    { "key": "dokkai", "max": 60, "min": 19 }
  ],
  "pass": 90,                               // 总分线（含聴解）；N3 95，N5 80
  "sections": [                             // N3–N5 为两节：moji-goi、bunpou-dokkai，节之间有休息页
    {
      "key": "gengo",                       // 言語知識
      "suggestMinutes": 30,
      "problems": [
        { "no": 1, "type": "kanji-yomi", "instructions": "＿＿＿の言葉の読み方として最もよいものを…", "ids": ["n2-m1-001", "…"] }
      ]
    },
    { "key": "dokkai", "suggestMinutes": 70, "problems": [ /* 問題 10–14 */ ] }
  ]
}
```

- 题目内容：`dist/quiz/N2/mock-1.json`（题干、选项、文章）
- 答案和解析：`dist/quiz/N2/mock-1.key.json`，**交卷后才请求**。不是防作弊（自测没必要），只是避免在网络面板或源码里不小心看到答案
- 两个文件都带 `?v=` 版本号，service worker 缓存后离线可做；key 文件也在开考时预缓存（离线交卷也能出成绩），但不读取

### 7.2 本地存储

在 `jp_quiz_v1` 里加 `mock`：

```jsonc
"mock": {
  "n2-mock-1": {
    "current": {                            // 进行中的一次，没有则为 null
      "mode": "full",                       // full | gengo | dokkai
      "start": 1730092800000,
      "paused": [[1730093400000, 1730093700000]],   // 暂停区间
      "answers": { "n2-m1-001": { "c": 2, "g": false, "f": false, "ms": 31000 } },
      "at": "n2-m1-042"                     // 当前所在题
    },
    "attempts": [
      {
        "mode": "full", "start": 1730092800000, "end": 1730099100000,
        "flags": ["informal"],              // informal | overtime | retake
        "answers": { /* 同上 */ },
        "score": { "gengo": 34, "dokkai": 16 }
      }
    ]
  }
}
```

一次整卷约 73 题 × 每题 ~40 字节 ≈ 3 KB，存几十次也没问题。导出 / 导入进度时一起带上。

## 9. 完成标准

- [ ] 手机上完整做完一套 105 分钟整卷，中途切 App、锁屏、刷新后都能接着做，时间不乱
- [ ] 时间到自动交卷；提前交卷有未答 / 标记提示
- [ ] 结果页：两科估算分 + 19 分线判断 + "聴解需要几分"、题型表、时间分析
- [ ] 逐题复盘能看解析、问 AI；错题一键进错题本，明天出现在「今日练习」
- [ ] 作答中不出现答案、解析、AI 按钮；答案文件交卷前不被读取
- [ ] 断网状态下能开始、作答、交卷、出成绩（之前打开过一次页面）
- [ ] 作者本人 12/6 前做完 3 套

## 10. 待定

1. **时间到：自动交卷还是可以超时继续**——倾向默认自动交卷（练真实压力），设置里可开"超时继续"
2. **估算分要不要按题型加权**：真考里读解一道题的分值大概率比语汇高，但官方不公开。第一期先按题数比例，等自己做了 3 套、对照 12 月真实成绩再校准（12/6 考完、成绩出来后可以拿自己的数据对一下）
3. **只做读解给 75 分钟还是 70 分钟**：整卷建议读解 70 分钟，单独做时多给 5 分钟检查时间，和整卷对齐的话应该是 70
4. **第 2、3 套难度要不要递增**：倾向不递增，三套等难度，分数变化才能反映进步
