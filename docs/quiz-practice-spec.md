# 练习模式（做题模式）· 详细规格

> 2026-10-28。展开 [quiz-plan.md](quiz-plan.md) §2.1。模拟模式共用这里的**做题组件**（§4），只是反馈时机和计时不同。

---

## 1. 目标

- 每天 10–15 分钟、手机上、通勤时能做：打开即做，不用设置
- 做题的结果要能变成"下一步练什么"：错题会回来，弱的题型排前面
- 每道题都能回到课文：做题是笔记的入口，不是另一套孤立的东西

## 2. 入口

| 入口 | 位置 | 进去之后 |
|---|---|---|
| 「今日练习」 | `/n2-practice/` 顶部大按钮 | 自动组 10 题（§5 的抽题规则），不用选 |
| 按题型 | `/n2-practice/` 题型列表 | 该题型 10 题 |
| 按课 | `/n2-practice/` 课列表；N2 总览页每课旁边 | 该课语法点的题 |
| 错题本 | `/n2-practice/` | 只抽到期的错题 |
| 课文内嵌 | 每个 `## N.` 语法点末尾「练 3 题」 | 在原页面展开作答，不跳页（§8） |

## 3. 一组题的流程

```
选范围 ──▶ 第 1 题 ──▶ 选项 ──▶ 判对错 + 解析 ──▶ 下一题 ──▶ … ──▶ 小结
            ▲                                                     │
            └──────────── 「重做错题」/「再来一组」 ◀───────────────┘
```

- 默认 10 题一组；设置里可改 5 / 10 / 20
- 中途离开：进度存本地，回来时提示「继续上一组（还剩 4 题）」/「放弃」
- 一组题不重复；同一组内不会连续出同一个语法点的两道题

### 3.1 答一道题

1. 看题干，点选项 → 选中态（再点一次或点「确定」才提交；设置里可改成"点了就提交"，默认是点了就提交，手机上少一步）
2. 提交前可以勾「**蒙的**」（选项下方一个小开关）：蒙对的题按"不会"处理，进错题本（§6）。真考里大量是蒙的，不标出来正确率会骗自己
3. 提交后：
   - 选项上色：正确答案绿、你选错的红，其余灰
   - 顶部一行：✅ 正确 / ❌ 正确答案是 2「にもかかわらず」
   - 解析自动展开（§3.2）
   - 答错或蒙的：解析上方一个醒目的「🤖 AI 讲解我为什么错」（§3.4）
   - 底部固定按钮「下一题」
4. 题目有问题 → 解析末尾「这题有问题」→ 选原因（答案错 / 两个都对 / 题干不通 / 其他）→ `gaEvent('quiz_report')`，本题不计入统计

### 3.2 解析的结构

每题固定 4 块，空的不显示：

| 块 | 内容 |
|---|---|
| 正解 | 为什么选它：接续 + 意思，一两句 |
| 干扰项 | 每个错误选项一行：错在哪（意思不对 / 接续不对 / 语气不对） |
| 完整句子 | 填好答案的整句 + 翻译；🔊（第二期，题目句子进 TTS 管线） |
| 相关语法 | 链到课文语法点（`refs`），新开浮层显示那一节，**不离开当前做题页** |
| AI | 「🤖 AI 讲解」（答对时也有，收在解析末尾，答错时提到最上面）→ §3.4 |

解析里的日文有振假名；题干默认没有（同真考），设置里可开。

### 3.4 AI 讲解

固定解析是写给所有人的；AI 讲解针对**你选的那个错误选项**，并且可以追问。

**点开之后**
- 复用现有 AI 侧边面板（手机上全屏），不另做一套聊天 UI；关掉面板回到原题，做题进度不受影响
- 自动带上的上下文：题干、四个选项、正确答案、**你选的答案**、是否标了"蒙的"、固定解析、`refs` 指向的课文那一节（接续 / 含义 / 例句 / 辨析）
- 第一条自动发出，按情况选问题：
  - 答错："我选了 3「ばかりに」，为什么不对？它和正确答案的区别是什么？"
  - 蒙对："这题我是蒙的，帮我讲清楚为什么是 1，下次怎么判断"
  - 答对后主动点开："再讲讲这几个选项的区别"
- 回答要求（写在 system prompt 里）：先一句话结论 → 你选的选项错在哪（意思 / 接续 / 语气）→ 正确选项为什么对 → 再给 1–2 个对比例句；日文按现有规则 `漢字（かな）` 显示振假名
- 面板底部快捷追问：「再举个例子」·「这两个语法怎么区分」（「再出 3 道类似的」等 AI 出题，见 quiz-plan.md §2.4，待定）

**不在答题前出现**：答题前不能问 AI，否则就是让 AI 替你做题。模拟模式交卷前同样隐藏。

**小结页**：「🤖 AI 总结这组错题」——把这组里错的 / 蒙的题（题干 + 你的答案 + 正确答案 + 语法点）一次发出，让 AI 找共性（例如"3 道错题都是把逆接和原因搞混"）并推荐复习哪几课。

**额度**
- 题库里的题是固定的，同一道题选同一个错误选项，第一条请求的内容完全相同 → 命中 worker 已有的边缘缓存（同问题 3 天内重复问不花 neurons，见 `worker/src/index.js` 的 `cacheable`）。所以 AI 讲解越多人用，单次越便宜
- 为了命中缓存，第一条请求里**不放**会变的东西（做题用时、日期、历史正确率）；"蒙的"只有两种取值，可以放
- 追问不走缓存，按普通问答计（实测约 127 neurons / 次）
- 不额外设每日次数，沿用 worker 现有的每 IP 6/分钟、50/天
- worker 的 `source` 白名单加 `quiz-explain`（单题讲解）和 `quiz-summary`（小结），分开计数
- 自带 key 的读者走自己的 provider，和现在的 AI 面板一样

**预生成（可选，第二期）**：对错误率最高的题，用 build 脚本提前为每个错误选项生成一份 AI 讲解，审过后写进题目 json 的 `explain.byChoice`，变成固定解析的一部分——不花线上额度，也不会出错

### 3.3 小结页

- 得分 7/10、用时、和这个题型以往的正确率比
- 错题列表：题干一行 + 你的答案 / 正确答案，点开看解析
- 按钮：「重做错题」·「再来一组」·「去复习：Lesson 63 §3」（错得最多的那个语法点）·「🤖 AI 总结这组错题」（§3.4）

## 4. 做题组件（三种模式共用）

一个组件，三种配置：

| 配置 | 练习 | 模拟 | AI |
|---|---|---|---|
| 反馈 | 每题 | 交卷后 | 每题 |
| 计时 | 只记录 | 倒计时 | 只记录 |
| 题号面板 | 无 | 有（已答/未答/标记） | 无 |
| 「蒙的」开关 | 有 | 有（交卷后才生效） | 有 |
| 写入错题本 | 是 | 交卷后可选 | 是（标来源 `ai`） |

### 4.1 各题型的界面

| 题型 | 题干展示 | 特殊交互 |
|---|---|---|
| 1 漢字読み | 句子里目标词加下划线 | — |
| 2 表記 | 目标假名加下划线 | — |
| 3 語形成 | 括号空位 | — |
| 4 文脈規定 / 7 文法形式 | 括号空位 | — |
| 5 言い換え | 目标词加下划线 | — |
| 6 用法 | 题干只有一个词 | 四个选项是**四个整句**，竖排大卡片 |
| 8 文の組み立て | `___ ___ ★ ___` 四个空 | **点选项依次填进空位**，可点空位撤回；四个都填完才能提交；判分只看 ★ 位置；解析显示完整正确顺序 |
| 9 文章の文法 | 一篇短文，空位编号 | 文章在上，当前空位高亮，题目在下 |
| 10–14 读解 | 文章 | 手机：文章占上半屏可滚动，题目是可上拉的底部面板；桌面：左文右题。一篇文章的几道题连着出 |

```
手机 · 問題7                        手机 · 問題8（★ 排序）
┌──────────────────────┐          ┌──────────────────────┐
│ 3/10  文法形式   ⏱ 0:42 │          │ 5/10  文の組み立て     │
│                      │          │                      │
│ 雨が降っている（　　）、│          │ あの店は ___ ___ ★ ___ │
│ 試合は予定通り行われた。│          │ 人気がある。           │
│                      │          │                      │
│ ┌──────────────────┐ │          │  [安い]  [だけ]       │
│ │1 にもかかわらず      │ │          │  [あって] [味もいい]   │
│ ├──────────────────┤ │          │                      │
│ │2 からといって        │ │          │ 已填：安い / だけ      │
│ ├──────────────────┤ │          │                      │
│ │3 ばかりに           │ │          │                      │
│ ├──────────────────┤ │          │                      │
│ │4 あげく             │ │          │                      │
│ └──────────────────┘ │          │                      │
│ ☐ 蒙的                │          │ ☐ 蒙的       [提交]   │
└──────────────────────┘          └──────────────────────┘
```

### 4.2 操作细节

- 选项是整行大按钮（≥48px 高）
- 桌面键盘：`1–4` 选项、`Enter` 提交 / 下一题、`G` 切换「蒙的」
- 结果用 `aria-live` 读出；颜色之外再加 ✓ / ✗ 图标（色弱）
- 深色模式沿用站点 token

## 5. 抽题规则（「今日练习」）

10 题按这个顺序填满：

1. **到期的错题**，最多 4 题
2. **最弱题型**的没做过的题：最近 20 次正确率最低的 2 个题型，共 4 题
3. **没做过的题**，按课程顺序（先学过的课），补满
4. 都做过了 → 最久没做的题

排除：`mockOnly` 的题（留给模拟卷）、被自己报告过有问题的题。

「正确率」只看**最近 20 次**，不看累计：反映现在的水平，进步了数字会动。

## 6. 错题本

间隔重复，简单版（不做完整 SM-2）：

| 事件 | 结果 |
|---|---|
| 答错 | 进错题本，第 0 级，**立刻到期** |
| 蒙对 | 进错题本，第 0 级，**明天到期** |
| 到期时答对 | 升一级：0→1（3 天后到期）→2（7 天后到期）→ 移出（掌握） |
| 到期时答错 | 回到第 0 级 |
| 未到期时又做到并答对 | 不升级（避免同一天刷掉） |

- 错题本页：按到期 / 按题型 / 按课分组；显示「今天到期 6 题」
- 手动移出（"这题我会了"）、手动加入（答对了但想再练）
- 第二期：导出为 Anki 牌组（复用 build-anki 的卡片格式）

## 7. 进度和统计

`/n2-practice/` 顶部：

- 今天做了 N 题 · 连续 N 天
- 各题型一行：做过 / 题库总数 · 最近 20 次正确率条 · 错题数；低于 60% 标红，点击直接练该题型
- 各课一行（折叠）：同上
- 「练最弱的」按钮 = 正确率最低的题型

只在本地，不上传。

## 8. 课文页内嵌

- build 时按题目的 `refs` 把题目 id 写进对应语法点：`<div class="quiz-inline" data-q="n2-bunpou-0012,…">`
- 按钮「练 3 题」，点了才加载题目 json，在原地展开同一个做题组件
- 没有题的语法点不显示按钮
- 做完显示 2/3，和「去练习页继续」链接；结果同样计入统计和错题本

## 9. 本地存储

一个 key：`jp_quiz_v1`，所有读写包 try/catch，读不到就当新用户。

```jsonc
{
  "v": 1,
  "answers": {                       // 每题最近 5 次
    "n2-bunpou-0012": [{ "t": 1730092800, "c": 1, "ok": false, "ms": 42000, "g": false }]
  },
  "review": {                        // 错题本
    "n2-bunpou-0012": { "lv": 0, "due": 1730092800, "src": "bank" }
  },
  "reported": ["n2-goi-0031"],
  "session": { "kind": "daily", "ids": ["…"], "i": 3, "picked": {} },   // 进行中的一组
  "days": { "2026-10-28": 12 },      // 每天做题数（连续天数用）
  "prefs": { "size": 10, "furigana": false, "instant": true }
}
```

- 规模：1000 题 × 5 次 ≈ 100 KB，远低于 localStorage 上限
- 题目改了答案：题目 json 加 `rev`，`rev` 变了就丢掉这题的历史和错题记录
- **备份**：设置里「导出进度（JSON 文件）/ 导入」，换手机或清缓存时用。不做账号

## 10. 双语

- 题干、选项：日语，两种语言页面相同
- 解析：`explain.zh` / `explain.en`，按页面语言显示；缺英文时显示中文并标注
- 界面文字：英文页纯英文，`/zh/` 纯中文（同站点规则）

## 11. 埋点

| 事件 | 参数 |
|---|---|
| `quiz_start` | kind（daily / type / lesson / review / inline / ai）、size |
| `quiz_answer` | type、ok、guess、ms 分桶 |
| `quiz_finish` | kind、score、size |
| `quiz_report` | id、reason |
| `quiz_ai` | kind（explain / summary / followup）、ok、guess |

不发题目内容和答案。

## 12. 完成标准

- [ ] 手机上从打开 `/n2-practice/` 到做第一题 ≤ 2 次点击
- [ ] 10 题一组完整做完，小结页显示错题，错题明天出现在「今日练习」
- [ ] 問題8 排序题在手机上能顺畅填空、撤回
- [ ] 刷新页面后能继续做到一半的一组
- [ ] 课文页「练 3 题」可用，结果计入统计
- [ ] 离线（service worker 缓存后）能做题
- [ ] 导出 / 导入进度可用
- [x] 答错后 1 次点击打开 AI 讲解，第一条回答针对自己选的选项；同一题同一选项第二次问命中缓存

## 13. 待定

1. **点选项就提交，还是选完再按「确定」**：默认点了就提交（快），但手机上误触会直接算错；可以只对問題 6、8 这种长选项要求「确定」
2. **「蒙的」开关会不会太麻烦**：每题都要想一下；也可以改成"用时超过 X 秒且答对"自动标为不确定。倾向保留手动开关，但默认收起
3. **题干振假名默认开还是关**：N2 真考没有；读者里 N3 水平来挑战的人可能需要。倾向默认关，第一次进入时问一次
